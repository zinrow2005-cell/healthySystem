# 健康監測 V14.5 — 日期與互動圖表版

## 修正
- Google Sheet 回傳的 ISO 日期（例如 2026-09-20T16:00:00.000Z）會自動以台灣時區轉成 2026/09/21。
- 體重紀錄、全部檢驗、健康報告、近期變化等日期統一顯示 YYYY/MM/DD。
- 編輯與刪除體重時仍使用標準 YYYY-MM-DD 資料鍵，避免時區造成找不到紀錄。
- Apps Script 日期格式固定使用 Asia/Taipei。

## 互動圖表
- 體重趨勢、首頁血糖/腎功能趨勢、趨勢分析頁全部改為互動式 Canvas 圖。
- 電腦：滑鼠移到資料點會顯示完整日期與數值。
- 手機/iPad：手指點資料點後資訊會保留顯示。
- Tooltip 顯示完整日期、數值與單位。

Apps Script 測試版本：V14.5
